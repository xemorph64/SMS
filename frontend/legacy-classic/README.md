# Classic UI (archived)

The original MailSentinel interface (matrix-green terminal look), kept for reference only.
It is **not built or served**: Vite and Tailwind only read `frontend/src/`, which now contains
the SIGNAL interface alone.

- `src/` is a snapshot of the classic entry (`App.jsx`, `index.css`, `components/`, `pages/`)
  plus a copy of `lib/` as it was when archived (2026-09-29).
- The same code is also preserved in git: tag `ui-classic-v1` and branch `ui-classic`.

To run it again, check out the tag: `git checkout ui-classic-v1 -- frontend/src`.
